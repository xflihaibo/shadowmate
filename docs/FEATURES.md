# 伴影 (Shadow Mate) 功能文档

本文档描述扩展的完整功能与交互逻辑，便于开发与维护时查阅。

---

## 一、产品概述

伴影是一款以「静默陪伴」为理念的 Chrome 扩展：在浏览过程中只做轻量记录，在归航时刻与首次打开时送上问候与总结，其余时间不打扰。所有数据仅存于本地，24 小时滚动保留，零上传。

---

## 二、Popup 功能（扩展弹窗）

### 2.1 顶部区域

| 功能 | 说明 |
|------|------|
| **每日格言** | 顶部标题，每日轮换的英文格言（如 "Shadow Mate · 数字归航"），不换行、过长省略。 |
| **全局开关** | 右侧开关，控制扩展是否启用（影响内容脚本的余晖/归航/剪贴板等）。 |
| **陪伴天数** | 显示「X 天」，为有浏览活动的不同天数累计（最多统计 365 天）。 |
| **里程碑勋章** | 达到 7/14/30/100/365 天时显示对应勋章与名称（如 7 天「初识」、365 天「一年之约」）。 |
| **每日一句** | 副标题区域，展示当日温馨短句；**可点击**，点击后显示「找到伴影」悬浮按钮并触发一次伴影互动气泡。 |

### 2.2 找到伴影（悬浮幽灵）

- **触发方式**：点击副标题「每日一句」后出现。
- **位置**：固定在弹窗左侧（约 left: 20px, top: 160px）。
- **图标**：使用 `icons/ghost.gif` 动图；加载失败时回退为 👻 emoji。
- **交互**：点击按钮会触发「伴影互动气泡」（从 `interactionLibrary.ts` 中随机选取温馨短句，在按钮右侧显示气泡，一段时间后自动消失）。
- **关闭**：无单独关闭按钮，再次打开 popup 或刷新后按逻辑会重新根据状态显示/隐藏。

### 2.3 晨间问候（每天第一次见面）

- **触发条件**：当天**第一次**打开 popup 时显示。
- **内容**：气泡文案为按时段变化的问候语（如「早，今天也一起吧 ✨」），图标为 `icons/ghost.gif`，加载失败回退 👻。
- **关闭**：右上角 × 可关闭，关闭后当天不再显示。

### 2.4 今日统计

四张统计卡片，数据来自当日浏览记录（由 background 聚合）：

- **活跃时长**：当日有焦点的活跃时间合计。
- **累计点击**：当日点击次数。
- **滚动距离**：当日滚动距离（米）。
- **敲击字数**：当日键入字符数。

### 2.5 剪贴板记忆

- **开关**：独立开关，可关闭剪贴板记录与自动填充。
- **列表**：最多 10 条复制历史，支持单条删除与「清空」。
- **说明**：详细交互与快捷键见 [剪贴板记忆功能文档](./CLIPBOARD_MEMORY.md)。

### 2.6 设置与其它

- **归航时刻**：时间选择器，设定「归航仪式」触发时间（如 18:00）；**余晖模式**会在该时间前约 30 分钟开始（网页淡橙滤镜 + 蜡烛图标提示）。
- **重置今日提示状态**：清除当日「已显示归航/已关闭提示」等状态，便于再次体验归航与提前提示。

## 三、内容脚本功能（注入到网页）

### 3.1 归航仪式（Sunset Ritual）

- **触发**：当前时间达到用户设定的「归航时刻」且当日尚未展示过时触发。
- **表现**：在页面右下角出现**伴影幽灵**气泡 + 可点击的**幽灵图标**；点击幽灵可展开「伴影 · 私语」卡片（今日叙事总结、统计、时间轴、关键词等）。
- **图标**：幽灵态使用 `icons/ghost.gif`；由 content 脚本通过 `chrome.runtime.getURL('icons/ghost.gif')` 加载。

### 3.2 余晖模式（Golden Hour）

- **时段**：归航时刻前约 30 分钟开始，到归航时刻结束。
- **表现**：
  - 全页叠加淡橙色滤镜（`mix-blend-mode: multiply`），随接近归航时间逐渐加深。
  - 在归航时刻之前：右下角显示**蜡烛图标**（`icons/lazhu.png`）作为「即将归航」的提前提示；到达归航时刻后，同一位置切换为**幽灵图标**（ghost.gif）并触发归航仪式。
- **关闭**：用户可点击蜡烛/幽灵上的 × 关闭；关闭后当日不再显示余晖与归航（可经 popup「重置今日提示状态」恢复）。

### 3.3 数字漂流瓶（Time Capsule / 见过面回忆）

- **触发**：用户再次访问曾在 12 小时以前有较高互动（如键入较多字）的页面时。
- **表现**：在页面右下角出现**伴影幽灵** + 气泡文案（如「嗨，我们在 X 月 X 日见过。当时你在这里留下了 X 个字……」）；图标为 `icons/ghost.gif`。

### 3.4 剪贴板记忆（页面内）

- **自动填充**：焦点进入输入框（input/textarea 等）时，可自动填充最近一次复制内容；支持 **↑/↓** 在历史中切换，并显示预览提示。
- **细节**：排除密码框等敏感控件；与 popup 的剪贴板列表共用同一套存储与开关。详见 [CLIPBOARD_MEMORY.md](./CLIPBOARD_MEMORY.md)。

## 四、图标与资源（icons）

| 文件 | 用途 |
|------|------|
| **logo.png** | 扩展在工具栏与安装页的图标；popup 内默认站点图标。 |
| **ghost.gif** | 悬浮「找到伴影」按钮、晨间问候、内容脚本中的归航幽灵与回忆幽灵。 |
| **ghost.png** | 当前未在弹窗/内容脚本中使用（可作备用或其它入口）。 |
| **lazhu.png** | 余晖时段「提前提示」的蜡烛图标（内容脚本）。 |
| **logo.svg / promotional_banner.svg** | 设计/商店用，代码中未引用。 |

构建时会将 `icons/` 目录完整复制到 `dist/icons/`，并通过 `web_accessible_resources` 声明，以便 popup 与 content 通过 `chrome.runtime.getURL('icons/xxx')` 加载。

---

## 五、数据与隐私

- **存储**：全部使用 `chrome.storage.local`，包含当日浏览统计、剪贴板历史、陪伴天数、归航/提示关闭状态等。
- **保留**：浏览相关数据按 24 小时滚动清理；陪伴天数保留最近 365 天。
- **上传**：无；无远程服务器、无上报。
