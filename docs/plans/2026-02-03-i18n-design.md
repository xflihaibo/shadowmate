# 伴影 (Shadow Mate) 中英文多语言设计

**日期**：2026-02-03  
**范围**：扩展内 UI 多语言（popup + content script），不含 manifest/商店描述。  
**策略**：默认跟随浏览器语言，用户可在设置中覆盖为中文或 English。

---

## 1. 语言解析与存储

**当前语言判定：**

- 读取 `chrome.storage.local` 中的 `languageOverride`。
- 若存在且为 `"zh"` 或 `"en"`，则**当前语言**为该值。
- 若不存在或为空，则**当前语言**由浏览器语言决定：使用 `navigator.language`（或扩展环境中的 `chrome.i18n.getUILanguage()`），前两位映射为 `zh` / `en`，其余统一视为 `en`。

**存储约定：**

- 仅当用户在设置中**主动选择语言**时写入 `languageOverride`。
- 设置项为「中文」「English」两项；选择后持久化，清除或删除该键表示未覆盖、跟随浏览器。
- 若需显式「跟随系统」选项，可存 `null` 或 `""` 表示不覆盖。

**文案来源：**

- 扩展内 UI 不依赖 Chrome `_locales`（manifest/商店若未来多语言可单独处理）。
- 文案存放在项目内 JSON：`src/locales/zh.json`、`src/locales/en.json`，通过 key 引用（如 `greeting.morning`）。popup 与 content 共用同一套 key。

---

## 2. 文案结构与 Popup 用法

**文案结构：**

- 两文件结构一致，key 一一对应。
- key 采用命名空间 + 语义，例如：`popup.title`、`popup.stats.activeTime`、`content.ritual.greeting`、`content.goldenHour.message`。
- 含占位符时使用简单约定，如 `"summary.line": "今日你 {category}，在 {site} 停泊最久。"`，运行时做占位替换（轻量 replace，不引入完整 i18n 库）。

**Popup（Vue）侧：**

- 提供轻量 i18n 能力：如 `src/popup/i18n.ts` 或 `composables/useI18n.ts`，内部从 storage 读当前语言、加载对应 JSON（或构建时打包 zh/en，按语言取用），暴露 `locale`（`'zh' | 'en'`）和 `t(key, placeholders?)`。
- 在设置区增加「语言」选项：中文 / English。变更时写入 `languageOverride` 并刷新当前视图（或重载 popup）。
- 所有原硬编码中文改为 `t('popup.xxx')`；每日格言等若来自 `interactionLibrary`，按 key 放入 locales 或在该结构中按 locale 取值。

---

## 3. Content 脚本如何用同一套语言

**语言：**  
在展示 UI 前，content 通过 `chrome.storage.local.get('languageOverride')` 判断是否被覆盖；未覆盖时用 `navigator.language` 判定 zh/en。可实现 `getEffectiveLocale(): Promise<'zh'|'en'>` 在 content 内复用。

**文案：**

- **推荐**：构建时将 `zh.json` / `en.json` 打入 content bundle（如 content 入口 `import zh from '../locales/zh.json'`，按 locale 选用）。content 不依赖 popup/background 传消息，逻辑简单、离线可用。
- **备选**：由 background 或 popup 将「当前 locale + 当前语言 messages」写入 storage，content 只读 storage；需额外维护写入时机与读取顺序。

**使用：**  
归航卡片、余晖提示、时间胶囊气泡、统计标签等所有硬编码中文改为从 messages 按 key 取（如 `content.ritual.title`、`content.goldenHour.*`、`content.timeCapsule.*`）；占位符与 popup 同一套替换规则。popup 与 content 共用同一套 key 命名。

---

## 4. 兜底与边界

- **缺 key**：先回退到另一语言同 key；若仍无则显示 key 或占位文案（如 `"[missing: popup.stats.activeTime]"`），便于发现漏翻。
- **无效/缺语言**：`languageOverride` 非 `zh`/`en` 时视为未设置，按浏览器语言；浏览器无法映射时默认 `zh`。
- **首次加载**：Popup 在拿到 locale 与 messages 后再渲染，避免先闪一种语言再切换。Content 在注入归航/余晖/时间胶囊等 UI 前先 `await getEffectiveLocale()` 并取好 messages，再拼文案，避免闪烁。

---

## 5. 实现清单与测试要点

**实现清单：**

| 项 | 说明 |
|----|------|
| 新增 | `src/locales/zh.json`、`src/locales/en.json`（按 FEATURES 与现有代码拆 key，中英各一份） |
| 新增 | `src/i18n.ts` 或 `src/shared/i18n.ts`：`getEffectiveLocale()`、`t(locale, messages, key, placeholders?)` 及回退逻辑；popup 可再封装为 `locale` + `t(key)` |
| Popup | 设置区加「语言」选项；所有界面文案改为 `t('popup.xxx')`；`interactionLibrary` 按 key 从 locales 取 |
| Content | 渲染 UI 前 `await getEffectiveLocale()`，按 locale 使用对应 JSON；硬编码中文改为 key；占位符统一替换 |
| 构建 | 确认 content 入口可 import `locales/*.json`（Vite 默认支持），content 按 locale 选一份使用 |

**测试要点：**

- 未设置 `languageOverride`：浏览器中文 → 扩展内全中文；浏览器英文 → 全英文（需重开 popup / 刷新页面验证 content）。
- 设置中选 English：popup 与 content（归航、余晖、时间胶囊等）均为英文；改回中文后均为中文。
- 清空 `languageOverride` 后行为与「未设置」一致，跟随浏览器。
- 检查所有文案均有对应 key，英文无漏翻，占位符替换正确。
