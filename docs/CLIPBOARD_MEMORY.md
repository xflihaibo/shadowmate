# 剪贴板记忆功能文档

## 📋 功能概述

剪贴板记忆功能是「伴影 (Shadow Mate)」的核心功能之一，它能够智能记录你复制的内容，并在需要时自动填充到输入框中，大大提升你的工作效率。

### 核心特性

- ✅ **自动记录**：自动捕获浏览器内复制和外部应用复制的内容
- ✅ **智能去重**：自动检测并过滤重复内容，避免历史记录冗余
- ✅ **键盘导航**：使用上/下箭头键快速切换不同的复制历史
- ✅ **内容预览**：切换时显示当前填充内容的预览提示
- ✅ **跨网站共享**：所有网站共享同一份剪贴板历史
- ✅ **持久化存储**：页面刷新后数据仍然保留
- ✅ **可视化管理**：在 popup 中查看和管理所有复制历史

## 🎯 使用场景

### 场景 1：浏览器内复制
1. 在网页中选中文本
2. 按 `Ctrl+C`（Mac: `Cmd+C`）复制
3. 内容自动保存到剪贴板历史

### 场景 2：外部应用复制
1. 从其他应用（记事本、Word、Excel 等）复制内容
2. 在浏览器中点击任意输入框
3. 系统自动检测并保存剪贴板内容
4. 或者直接在输入框中粘贴（`Ctrl+V`），内容也会被保存

### 场景 3：快速填充
1. 点击任意输入框（input/textarea）
2. 系统自动填充最近复制的内容
3. 使用 **上箭头键** 切换到更早的记录
4. 使用 **下箭头键** 切换到更新的记录
5. 预览提示框会显示当前填充的内容

### 场景 4：历史管理
1. 点击扩展图标打开 popup
2. 在「复制历史」区域查看所有记录
3. 点击 **×** 按钮删除不需要的记录
4. 每条记录最多显示 2 行，超出部分显示省略号

## ⌨️ 快捷键说明

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+C` / `Cmd+C` | 复制 | 复制选中的文本，自动保存到历史 |
| `Ctrl+V` / `Cmd+V` | 粘贴 | 粘贴内容，同时保存到历史 |
| `↑` (上箭头) | 切换历史 | 在输入框中切换到更早的复制记录 |
| `↓` (下箭头) | 切换历史 | 在输入框中切换到更新的复制记录 |

**注意**：上/下箭头键只在输入框获得焦点时生效。

## 🔧 技术实现

### 数据存储

- **存储位置**：`chrome.storage.local`
- **存储键名**：`clipboardHistory`
- **数据结构**：
  ```javascript
  [
    {
      text: "复制的文本内容",
      timestamp: 1706342400000,  // 时间戳
      url: "https://example.com" // 复制时的页面 URL
    },
    // ... 最多 10 条
  ]
  ```

### 检测机制

系统使用多层检测机制确保不遗漏任何复制内容：

#### 1. 复制事件监听（浏览器内）
```javascript
document.addEventListener('copy', ...)
```
- 监听浏览器内的复制操作
- 从 `window.getSelection()` 获取选中文本

#### 2. 粘贴事件监听（外部应用）
```javascript
document.addEventListener('paste', ...)
```
- 监听粘贴操作
- 从 `e.clipboardData.getData('text/plain')` 获取内容
- 支持从外部应用复制的内容

#### 3. 输入框焦点检测
```javascript
document.addEventListener('focusin', ...)
```
- 输入框获得焦点时
- 使用 Clipboard API 读取剪贴板内容
- 捕获从外部应用复制但还未粘贴的内容

#### 4. 输入变化检测
```javascript
document.addEventListener('input', ...)
```
- 监听输入框值的变化
- 检测值突然增加（可能是粘贴操作）
- 从剪贴板读取并保存

### 去重逻辑

系统在保存前会检查所有历史记录，避免重复：

```javascript
const isDuplicate = clipboardHistory.some(item => item.text === trimmedText);
if (isDuplicate) {
  // 跳过保存
  return false;
}
```

**去重规则：**
- 完全匹配：文本内容完全相同
- 自动去重：不区分大小写和前后空格
- 实时检查：每次保存前都会检查

### 自动填充逻辑

**触发条件：**
1. 输入框获得焦点
2. 输入框为空（无内容）
3. 剪贴板历史中有记录

**填充规则：**
- 自动填充最近的一条记录（索引 0）
- 支持 `<input>`、`<textarea>` 和 `contenteditable` 元素
- 排除密码框、文件选择框、隐藏输入框

**键盘导航：**
- 上箭头：切换到更早的记录（索引 +1）
- 下箭头：切换到更新的记录（索引 -1）
- 循环切换：到达边界后自动循环

### 内容预览

**显示时机：**
- 自动填充时
- 使用箭头键切换时

**显示位置：**
- 输入框上方
- 黑色半透明背景
- 白色文字
- 自动定位，不遮挡输入框

**显示时长：**
- 显示后 2 秒自动隐藏
- 切换时立即更新

## ⚙️ 配置说明

### 存储限制

- **最大记录数**：10 条
- **超出处理**：自动删除最旧的记录
- **保留策略**：FIFO（先进先出）

### 权限要求

在 `manifest.json` 中需要以下权限：

```json
{
  "permissions": [
    "storage",        // 存储剪贴板历史
    "clipboardRead"   // 读取剪贴板内容（外部应用）
  ]
}
```

### 排除的输入框类型

以下类型的输入框不会触发自动填充：

- `type="password"` - 密码框
- `type="file"` - 文件选择框
- `type="hidden"` - 隐藏输入框

## 🐛 故障排查

### 问题 1：复制的内容没有保存

**可能原因：**
1. 扩展未启用（检查 popup 中的主开关）
2. 复制的内容为空或只有空格
3. 内容与最近一条记录重复

**解决方法：**
1. 打开 popup，确认主开关已开启
2. 检查浏览器控制台（F12）是否有错误信息
3. 尝试复制不同的内容测试

### 问题 2：外部应用复制的内容没有保存

**可能原因：**
1. 浏览器权限限制
2. Clipboard API 不可用
3. 未触发检测事件

**解决方法：**
1. 确保 manifest.json 中包含 `clipboardRead` 权限
2. 尝试在输入框中粘贴（Ctrl+V），这会触发保存
3. 点击输入框后再粘贴，确保有用户交互上下文

### 问题 3：自动填充不工作

**可能原因：**
1. 输入框已有内容
2. 输入框类型被排除
3. 剪贴板历史为空

**解决方法：**
1. 清空输入框后再点击
2. 检查输入框类型是否被排除
3. 确认剪贴板历史中有记录

### 问题 4：上/下箭头键不切换

**可能原因：**
1. 输入框未获得焦点
2. 剪贴板历史为空或只有一条
3. 键盘事件被其他脚本拦截

**解决方法：**
1. 确保输入框已获得焦点（点击输入框）
2. 复制多条不同的内容
3. 检查是否有其他扩展或脚本冲突

### 问题 5：预览提示框不显示

**可能原因：**
1. CSS 样式冲突
2. 输入框位置特殊（如 iframe 中）
3. z-index 被覆盖

**解决方法：**
1. 检查浏览器控制台是否有 CSS 错误
2. 预览框的 z-index 为 100000，应该足够高
3. 如果输入框在 iframe 中，可能需要特殊处理

## 📊 性能考虑

### 存储优化

- 使用 `chrome.storage.local` 本地存储，不占用网络
- 限制最大记录数为 10 条，控制存储大小
- 使用 WeakMap 缓存输入框值，避免内存泄漏

### 事件优化

- 使用事件委托，减少事件监听器数量
- 粘贴事件使用异步处理，不阻塞主线程
- 剪贴板检查只在必要时执行（焦点、粘贴时）

### 内存管理

- 使用 WeakMap 存储输入框缓存，自动垃圾回收
- 定期清理临时变量
- 限制历史记录数量，避免无限增长

## 🔒 隐私与安全

### 数据存储

- **本地存储**：所有数据仅保存在本地浏览器
- **零上传**：不会上传任何剪贴板内容到服务器
- **自动清理**：超出 10 条后自动删除最旧记录

### 权限说明

- `storage`：用于保存剪贴板历史到本地
- `clipboardRead`：用于读取剪贴板内容（仅限用户交互时）

### 安全建议

1. **敏感信息**：避免复制密码、密钥等敏感信息
2. **定期清理**：定期在 popup 中删除不需要的记录
3. **扩展管理**：只安装可信的扩展程序

## 💡 使用技巧

### 技巧 1：快速切换常用内容

如果你经常需要切换几个固定的文本（如邮箱、地址等），可以：
1. 先复制这些内容，让它们进入历史
2. 在需要时，点击输入框后使用上/下箭头快速切换

### 技巧 2：批量复制

如果需要复制多个内容：
1. 按顺序复制每个内容
2. 它们会按时间倒序保存在历史中
3. 在输入框中用上箭头切换到更早的内容

### 技巧 3：清理历史

定期清理不需要的历史记录：
1. 打开 popup
2. 查看「复制历史」区域
3. 点击不需要记录的 **×** 按钮删除

### 技巧 4：避免敏感信息

如果复制了敏感信息（如密码）：
1. 立即在 popup 中删除该记录
2. 或者复制其他内容，让敏感信息被挤出历史（最多 10 条）
