# 插件设计文档：伴影 (Shadow Mate)

## 1. 概述 (Overview)
**伴影 (Shadow Mate)** 是一款基于 Chrome Manifest V3 的深度人文关怀插件。它在工作时间内默默陪伴用户，记录浏览轨迹与行为特征；在下班时间（18:00）通过人格化的“数字幽灵”提供温馨的今日浏览总结与健康问候，旨在打破工具与人的边界，提供有温度的数字陪伴。

## 2. 核心功能 (Core Features)

### 2.1 全自动行为记录 (Silent Tracking)
*   **网站访问统计**：记录访问域名、网页标题及图标。
*   **活跃停留计时**：仅在页面处于活跃状态（有交互且在前台）时计时。
*   **内容关键词提取 (A)**：自动分析页面标题与元数据，构建每日内容基因图谱。
*   **情绪状态感知 (B)**：通过标签页切换频率、滚动速度波动推测用户心理状态（如专注、焦虑、冲刺）。
*   **物理劳动力统计 (C)**：统计鼠标点击次数、滚动总距离、大致录入字数。

### 2.2 18:00 下班仪式 (The 18:00 Ritual)
*   **触发机制**：每日 18:00 后，当用户首次刷新或打开网页时激活。
*   **拟人化气泡 (B)**：页面侧边弹出半透明拟人化气泡（Shadow Ghost），拖着流光弹幕问候语。支持手动关闭。
*   **心理独白问候**：基于当日数据生成的感性文字，结合智能分类推测用户心境。
*   **数据画像总结**：点击气泡展示精美的毛玻璃总结卡片，包含今日足迹、能量平衡条（专注 vs 休闲）、体力结算及今日轨迹时间轴。

### 2.3 沉浸式场景与记忆 (Advanced Features)
*   **余晖模式 (Golden Hour)**：从 17:30 开始，网页缓缓染上落日橙滤镜，幽灵变身为提灯者 🕯️。
*   **数字漂流瓶 (Time Capsule)**：自动捕捉深度交互的高光时刻并持久化存储，在用户再次访问时唤起重逢记忆 💭。
*   **智能行为分类**：自动识别工作、学习、社交、娱乐等站点，提供时间分配比例。

## 3. 技术架构 (Architecture)

### 3.1 核心组件
*   **Background Service Worker**: 
    - 数据汇总中心，管理全局定时器。
    - 负责 18:00 闹钟触发逻辑。
    - 处理跨标签页的数据持久化。
*   **Content Scripts**:
    - 低功耗监听器，捕捉 DOM 事件（click, wheel）。
    - 页面信息提取器（title, favicons）。
    - 负责渲染 18:00 后的 UI 注入。
*   **Storage**: 
    - 使用 `chrome.storage.local` 进行本地化存储，严控隐私，不上传服务器。

### 3.2 关键算法
*   **活跃度判定**：利用 `document.visibilityState` 和交互事件流判定真实停留时间。
*   **关键词加权**：基于标签层级（如 h1 > p）和停留时间动态调整词语权重。

## 4. 隐私与安全 (Privacy & Security)
*   **数据不出域**：所有原始行为轨迹严格存储于本地。
*   **温柔过滤**：算法识别非工作类网站，总结时自动进行隐私模糊处理。

## 5. 成功标准 (Success Criteria)
*   用户在 18:00 后能感受到明显的、不突兀的心理慰藉。
*   插件运行期间对系统 CPU 和内存的占用率低于 1%。
*   数据记录准确，能还原出一天的核心工作重心。
