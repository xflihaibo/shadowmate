# 伴影 · 陪伴向功能创意

> 围绕「静默陪伴、归航仪式、私语叙事」的调性，可落地的陪伴向功能点子。

---

## 伴影人格 / 设计原则（优先遵守）

- **温馨**：语气与文案都偏温暖、不评判，像一位温柔的朋友。
- **每天换不同的提示词**：晨间问候、归航私语等按日/按时段轮换文案，不重复、有新鲜感。
- **安静的陪伴**：平时只做静默记录，不打扰、不弹窗、不刷存在感。
- **早上安静问安**：仅在你**当天第一次打开 Popup** 时，轻量一句问候（悬浮幽灵+气泡），可关闭、可自动消失。
- **下班给你互动**：只在**归航时刻**（你设定的时间）出现余晖与仪式，送上今日私语与小结，这是伴影一天里唯一的主动「互动」。
- **其他时间不需提醒**：不做休息提醒、不做专注时段结束提醒等；除晨间问安与归航互动外，其他时间零打扰。

新增功能若会「在其他时间主动提醒用户」，需先对照本条原则再决定是否做。

---

## 找到伴影 · Popup 内互动 ✅ 已实现

- **入口**：Popup 底部「👻 找到伴影」按钮，用户主动点击才出现，不打扰。
- **内容**：每次点击随机展示其一——**诗句** / **冷知识** / **与当前时段、星期相关的温暖话**；内容来自 `interactionLibrary.ts`，按日期与当日点击次数做种子轮换，保证**动态不重复**。
- **限制**：每日最多互动 **10 次**，超过后展示超限提示（如「你要好好工作」「我也是有脾气的不能一直陪你玩耍」「今日陪玩次数已用完明日再来」等随机一句）。
- **展示**：以**悬浮气泡**形式出现在 Popup 右下角，8 秒自动消失或可点击 × 关闭；进入/离开复用晨间问候的丝滑动画。
- **存储**：`interactionCountToday`、`lastInteractionDate` 仅用于限次，跨日自动清零。

## 一、晨间与节奏

### 1. 晨间问候 / 首次打开问候 ✅ 已实现
- **想法**：用户当天第一次打开浏览器（或第一次打开某个标签）时，伴影轻量出现一次：一句「早，今天也一起吧」或根据时段「早安 / 午安」，可选配当日 motto 或一句短 tip。
- **形态**：小气泡或右下角轻提示，几秒后自动消失，不打断操作。
- **实现**：background 用 `lastOpenedDate` 判断「是否今日首次」，content 在合适时机（如 document_idle + 可见）展示一次；或 popup 首次打开时展示一句问候。

### 2. 休息提醒 / 歇一歇 ❌ 不做
- **与原则冲突**：「其他时间不需提醒」——伴影只在晨间问安与归航时刻互动，其余时间静默陪伴，故不做休息提醒。

### 3. 专注时段 / 静默陪伴
- **想法**：用户可设置「专注时段」（如 14:00–16:00）。这段时间内：不弹仪式、不弹休息提醒，只静默记录。结束后轻量一句：「刚刚 2 小时你很专注，辛苦了。」
- **形态**：设置里增加「专注时段」起止时间；结束时一次小气泡或 popup 内一句文案。
- **实现**：popup/options 存 `focusStart`、`focusEnd`；content/background 在计时与提醒逻辑里跳过该时段，结束时发一次 message 或写一条「今日专注摘要」供 popup 展示。

## 二、归航与收尾

### 4. 今日一句 / 归航日记
- **想法**：在归航仪式卡片底部增加可选输入：「给今天写一句话」。仅存本地，不分析、不上传。之后可在「本周小结」或「昨日回顾」里看到这句话，形成「与过去的自己对话」。
- **形态**：仪式卡片底部一行输入框 + 保存按钮；popup 可增加「昨日/本周私语」区域展示历史句。
- **实现**：`chrome.storage.local` 存 `dailyOneLine: { date: string, text: string }[]`，按日写入；popup 按日期展示。

### 5. 收尾清单 / 未关标签 gentle 提醒
- **想法**：余晖或归航时刻，若当前窗口未关标签较多（如 ≥5），轻量提示：「还有 N 个标签开着，要存到稍后读吗？」附一个「复制当前所有标题+URL 为文本」的按钮，方便用户自己整理。
- **形态**：仪式卡片内一小块，或单独小气泡；不强制，一点即可关闭。
- **实现**：background 用 `chrome.tabs.query({ currentWindow })` 取数量；归航时若超过阈值，在 content 的仪式 UI 里加一块文案 + 复制逻辑（不涉及书签 API，仅复制文本）。

### 6. 连续归航 / 小 streak
- **想法**：轻量记录「连续几天在归航时刻前收工」（以「当天有过归航仪式或关闭余晖」为标记）。在 popup 或仪式卡片里一句：「已连续 N 天在归航时刻前收工」。
- **形态**：无勋章、无压力，仅一句陈述；可选配一句温和鼓励。
- **实现**：storage 存 `lastRitualDates: string[]`（最近若干天的日期），每日凌晨或首次打开时更新；连续天数 = 从今天往前数连续命中天数。

## 三、记忆与重逢

### 7. 故地重游 · 增强
- **想法**：在现有「12h+ 重访高互动页」基础上，加一句时间感：「上次来这里是 3 天前，当时你看了约 20 分钟。」让伴影更像「记得你上次来过」的陪伴者。
- **形态**：与现有 Time Capsule 气泡合并，多一行「上次访问」的简短描述。
- **实现**：在现有 `highlightMoments` 或浏览记录里按 URL 聚合「最近几次访问的日期+时长」；重访时取「上一次」算间隔与时长，拼成一句本地文案。

### 8. 去年的今天（可选）
- **想法**：若本地保留「去年同日的浏览摘要」（如仅保留「去年今日访问过的 host 数量、总时长」），在合适时机（如晨间问候或 popup 打开）轻量一句：「去年的今天你也在浏览器里度过了 N 分钟。」不展示具体站点，仅时间感。
- **形态**：popup 内一句，或晨间问候里顺带一句。
- **实现**：需在隐私策略下保留「去年今日」的聚合统计（例如只存 `{ date: 'MM-DD', totalMins: number, hostCount: number }`），且需在 README/隐私说明里写清「仅本地、仅聚合」。

## 四、周度与反思

### 9. 周度小结 / 本周陪伴
- **想法**：每周一次（如周日晚上或用户设置「周小结日」）在 popup 或一次轻提示里展示「本周陪伴小结」：本周总时长、最常去的几类站点、一句短叙事（如「这一周你主要在代码与阅读里度过」）。
- **形态**：popup 内新 tab「本周」或归航时刻若恰逢周日则仪式卡片多一块「本周小结」。
- **实现**：background 或 popup 按「本周一～今天」聚合现有 `browsingData`（若需更长周期需扩展保留策略）；叙事沿用现有分类与关键词逻辑，按周聚合。

### 10. 今日意图 / 轻量反思（可选）
- **想法**：晨间或 popup 首次打开时，可选填一句「今天想完成的一件事」或「今天想少做的一件事」。归航时若用户写过，私语里可带一句：「早上你说想完成 X，今天在 Y 上花了最多时间。」不评判，只呈现。
- **形态**：popup 顶部可选折叠区「今日意图」；归航叙事中可选插入一句。
- **实现**：storage 存 `todayIntention: string`，按日覆盖；生成私语时若存在则拼进模板。

## 五、语气与人格

### 11. 叙事语气（每日轮换）✅ 已实现
- **想法**：归航私语不设固定「性格」，而是**温暖 / 诗意 / 可爱**三种温馨文案，**按日期自动轮换**（同一天同一种，不同天换一种），让陪伴感自然变化。
- **形态**：无设置项；content 的 `generateShadowNarrative` 用 `getDailyToneIndex(今日日期, 3)` 选 tone，再选对应模板。
- **实现**：`NarrativeTone = 'warm' | 'poetic' | 'cute'`；温暖（原有句式）、诗意（停泊/粒字/行路）、可爱（扑腾/溜达/摸鱼～辛苦啦 ✨）。

### 12. 随机小句 / 偶尔彩蛋
- **想法**：在气泡、仪式卡片或 popup 的副标题处，偶尔（如 10% 概率）替换为一句彩蛋句：诗句、冷知识、或与当前时段/星期相关的一句温暖话，让伴影有一点「性格」。
- **形态**：与现有 daily quote 类似，但出现位置或概率不同，避免喧宾夺主。
- **实现**：维护一个小句池，按日或按打开次数做简单随机；仅前端本地。

## 建议优先做的 3 个（陪伴感强、实现成本可控）

1. **晨间问候**：今日首次打开时一句「早，今天也一起吧」+ 当日 motto，建立「每天都有伴影在」的感觉。
2. **今日一句**：归航时可选写一句话存本地，后续在周小结或昨日回顾里看到，强化「与过去的自己对话」。
3. **休息提醒**：连续活跃 N 分钟后轻量提醒「歇一歇」，体现伴影关心的是「你这个人」而不只是数据。
