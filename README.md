# 伴影 (Shadow Mate)

> **你是数字世界的航行者，而我是你身后的影子。**

「伴影」是一款专注于每日数字生活感性回顾的 Chrome 扩展程序。它不仅精准记录你的浏览统计，更通过独有的“私语引擎”将枯燥的数据转译为富有情感温度的叙事化总结。

**完整功能说明**：参见 [功能文档](./docs/FEATURES.md)。

---

## ✨ 核心特性

### 1. 归航仪式 (The Sunset Ritual)
在你设定的“归航时刻”（如 18:00），伴影会悄然浮现（幽灵动图），为你送上今日的“私语总结”。支持自定义归航时间，让下班充满仪式感。

### 2. 沉浸式余晖 (Golden Hour)
临近归航前的约 30 分钟，网页会泛起淡淡的橙色余晖（`mix-blend-mode: multiply`），并亮起**蜡烛图标**（lazhu.png）作为提前提示；到达归航时刻后切换为**幽灵图标**（ghost.gif），温柔提醒你从繁忙的数字世界中缓缓归航。

### 3. 找到伴影与晨间问候
- **找到伴影**：在 popup 中点击副标题「每日一句」后，左侧出现悬浮幽灵按钮（ghost.gif）；点击可触发伴影互动气泡。
- **晨间问候**：每天第一次打开 popup 时，显示问候气泡与幽灵图标（ghost.gif），可关闭后当日不再显示。

### 4. 陪伴天数与里程碑勋章
根据有浏览活动的不同天数累计「陪伴天数」，达到 7 / 14 / 30 / 100 / 365 天时展示对应勋章与名称（如「初识」「一年之约」）。

### 5. 伴影 · 私语 (Shadow Narrator)
基于用户行为特征（停留最久站点、活跃领域、键入强度等）生成的叙事化文案。归航时点击幽灵可展开卡片：今日轨迹时间轴、时长加权关键词、活跃时长 / 点击 / 滚动 / 键入等统计。

### 6. 数字漂流瓶 (Time Capsule)
当你重访曾留下高互动（如大量键入）的网页且距上次访问超过 12 小时时，伴影会带着当时的回忆浮现（幽灵动图 + 气泡文案）。

### 7. 剪贴板记忆 (Clipboard Memory)
智能记录复制内容（最多 10 条），输入框聚焦可自动填充，↑/↓ 切换历史并带预览。所有数据本地存储，popup 内可开关与清空。详见 [剪贴板记忆功能文档](./docs/CLIPBOARD_MEMORY.md)。

## 🛡️ 隐私与安全

**隐私是伴影的基石。**
- **零上传**：所有浏览记录、点击统计、输入内容分析仅保存在您本地的 `chrome.storage.local`。
- **本地处理**：数据分析与私语生成完全在浏览器本地执行，不连接任何远程服务器。
- **滚动清理**：数据仅保留 24 小时，过期自动物理删除。

## 🛠️ 技术栈

- **Vite + Vue 3 + TypeScript**：现代前端构建与开发体验。
- **@crxjs/vite-plugin**：Chrome 扩展与 Vite 集成，热更新开发。
- **Manifest V3**：遵循最新的 Chrome 扩展标准。
- **Background Service Worker**：基于 Tab 状态与窗口焦点的精准计时引擎。
- **CSS Glassmorphism**：毛玻璃风格 UI 设计，极致的视觉体验。
- **Context-Safe Messaging**：具备物理熔断保护的底层通信机制，解决 `context invalidated` 报错。

## 🚀 安装指南 (开发者模式)

### 构建与加载

1. 克隆本项目，在项目根目录执行：
   ```bash
   npm install
   npm run build
   ```
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，**选择本项目下的 `dist` 目录**（构建产物）。
5. 在插件栏固定“伴影”，开始你的温情探索。

### 开发模式（热更新）

```bash
npm run dev
```

保持终端运行，在扩展管理页对“伴影”点击“重新加载”即可看到代码变更效果。加载扩展时仍选择 `dist` 目录。
